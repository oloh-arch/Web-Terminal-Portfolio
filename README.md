# Web Terminal Portfolio

A retro green command-line portfolio website built with HTML, CSS, and vanilla JavaScript. Visitors type commands (`help`, `about`, `skills`, `projects`, `contact`, `clear`) to explore my profile and skills.

## Handover Note
- **What it is:** A single-page green retro web terminal portfolio site.
- **How to use it:** Open the live GitHub Pages link, type a command, and press `Enter`.
- **What is not included:** No backend server, database, login system, or mobile touch buttons.
